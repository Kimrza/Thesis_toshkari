### `IMPL-15` — REQ-ENG-12 contradicts D-144's express approval of the acquisition notebook

- Reviewer: Implementation Reviewer
- Severity: `BLOCKER`
- TEC gate / AI-DLC stage: G-P2, G-09 / 2.3
- Requirement: TE §14 line 774 — *"The **four** analysis/review notebooks import functions from `src/` and read versioned artifacts; **they** must not contain the only copy of parsing, calibration, feature, split, training, evaluation, or bootstrap logic. `00_acquire_phase1_vtec.ipynb` is a narrowly approved **self-contained** acquisition/audit interface after D-144"*; and line 784 — *"Each **analysis/review** notebook begins with the dataset version, code commit, configuration IDs, and artifact IDs it expects. - Evidence: REQ-ENG-12 as written — *"Each of the five notebooks declares its dataset version, code commit, config IDs and artifact IDs"* and *"No notebook holds the only copy of parsing, calibration, feature, split, training, evaluation or bootstrap logic"*.
- Observed mismatch: both rules are scoped by TE §14 to the four analysis/review notebooks. REQ-ENG-12 applies them to all five, and TE §14 assigns the acquisition notebook a **different** declaration set which REQ-ENG-12 does not state at all.
- Consequence: as written, the requirement makes an artifact approved under D-144 non-conformant, and omits the declaration set that notebook actually owes. A Construction agent implementing REQ-ENG-12 literally would either rewrite an approved interface or fail its own acceptance check.
- Smallest acceptable remediation: split the requirement — the four analysis/review notebooks take the four-item declaration set and the no-only-copy rule; the acquisition notebook takes its six-item set (own version, year/stations, source URLs, retrieval timestamp, destination paths, resulting hashes) and its four prohibitions, with its self-contained status cited to D-144.
- Closure evidence: REQ-ENG-12 restated with both scopes; a reviewer check that `00_acquire_phase1_vtec.ipynb` is not required to import from `src/`.
- Owner / due gate: Student + Supervisor (D-144 scope) / G-P2.
